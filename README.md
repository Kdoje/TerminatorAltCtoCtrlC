## Overview
The name is the description, intercepts calls to `Alt+c` to feed an interrupt character to the terminal in terminator

## Install Instructions
1. Clone the repo to your `Terminator Plugins` directory (by default `~/.config/terminator/plugins)
2. Restart Terminator
3. Navigate to Plugins in the Terminator Preferences
4. Tick the box for the `AltCtoCtrlC` Plugin
5. Observe `Alt+c` emits the interrupt character in the terminal
6. Note that `Ctrl+c` will still do the interupt as usual
